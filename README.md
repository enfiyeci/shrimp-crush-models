# How many shrimp get crushed in the net?

A computer model of shrimp being crushed in trawl nets: what share of the catch may be crushed in seven fisheries, where in the haul it happens, and how sure we are. The technical detail (every assumption and source) is in the folded sections at the end of the page.

Read it here: https://enfiyeci.github.io/shrimp-crush-models/

Arda Enfiyeci, with mentor Jan Gaida, Sentient Futures Project Incubator, fall 2026. Results come from the model version of 27 October 2026. Every percentage is a model estimate, not a measurement.
