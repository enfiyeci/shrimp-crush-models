# Shrimp Crush Models

Four computer models of shrimp being crushed in trawl nets: what each assumes, where every number comes from, and what share of the catch may be crushed in seven fisheries.

Read it here: https://enfiyeci.github.io/shrimp-crush-models/

Arda Enfiyeci, with mentor Jan Gaida, Sentient Futures Project Incubator, fall 2026. This is the working page of 28 October 2026. Every percentage is a model estimate, not a measurement.
